the library, not a picture of it

The chain below is simulated. The SDK has no Windows binary, so Vite is running in mock mode and @miden-sdk/miden-sdk is aliased to an in-memory stand-in. Everything else on this page is the real library: sendEnvelope draws the tags, fetchPool sweeps the pool, metric computes the observers. Notes are recorded by the mock, not executed. The run takes about twelve seconds. Watch it once before touching anything.
