miden-envelope · redesign plan

Thirty-five steps, in order.

Foundations first, then one element at a time. Every step has an ID so you can reject it by name without stopping the rest.

The 121 element IDs from the map are unchanged and still the thing being redesigned. These are a second, parallel numbering: RD is a step, not an element.

Already decided

UI-001 to UI-007 · logged
UI-001

Surface from your Voice Lab sheet: paper, hairline rules, micro-labels with a pumpkin square, poster-scale display type. Palette read from the live stylesheet, not sampled.

UI-002

Each observer gets one plain word. Not a metaphor, not a crypto term. All three current names fail.

UI-003

Faces are drawn by an artist, to an art direction we agree. No emoji, no icon glyphs. The third one must have exactly one expression.

UI-004

Copy is plain speech. If a word needs looking up, the line is wrong.

UI-005

The honesty badge leaves the header. The statement moves to the footnote.

UI-006

Colour by role. Three accents, one per observer — pumpkin, brass, oxblood — and no fourth hue. The three background washes are deleted; the colour they were carrying moves onto the spotlit panel's own border and face.

UI-007

Art direction. One-colour line drawings: no shading, no gradients, no 3D. Stroke heavier than an icon set. Faces cropped close and slightly off-centre, drawn from shared geometry. The third observer has exactly one drawing, permanently.

What is still yours

none · all settled

Every question that was yours has an answer now. Names (RD-14) and metric chips (RD-17) settled 2026-10-23. If any of them turns out wrong in use, say the ID and what is wrong and it gets reopened — nothing here is permanent until it survives being looked at.

Seven values, three of them chromatic. The layout carries three because it uses each one for a different character and never two at once. A fourth chromatic value would break that, so the palette stops here unless something is removed. Settled: one accent per observer, nothing borrows another's, and the background washes are gone — the colour moves onto whichever panel the current beat is about.
